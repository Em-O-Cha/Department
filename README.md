# ระบบงานองค์กร (หลายแผนก) — Google Apps Script Web App

## 👉 [เปิดระบบงานองค์กร](https://em-o-cha.github.io/Department/)

หน้าเว็บอยู่บน GitHub Pages (repo `Em-O-Cha/Department`, ไฟล์ `index.html`) ไม่มีแถบ Google Apps Script
ข้อมูลและรหัสผ่านทำงานที่ Google Apps Script ผ่าน `Api.gs` (doPost) · เปิดลิงก์ Apps Script ตรง ๆ จะเจอหน้าแจ้งลิงก์ใหม่

เว็บแอปกลางที่ใช้ร่วมกัน 8 แผนก: ฝ่ายบุคคล (HR), ฝ่ายบัญชี, จัดซื้อ & สต๊อกสินค้า, ฝ่ายประกันคุณภาพ (QA),
วิจัยและพัฒนา (RD), ฝ่ายผลิต, ความปลอดภัยและสิ่งแวดล้อม (SHE), ขนส่งและคลัง (LOG) — แต่ละแผนกเข้าด้วยรหัสผ่านของตัวเอง แยกกันโดยสิ้นเชิง

> สถานะ: **โครงหน้าตา** — หน้าแรก / กรอกรหัสผ่าน / หน้าหลักแผนก / เมนูตัวอย่าง
> ยังไม่มีฟอร์มกรอกข้อมูลและยังไม่ได้เชื่อม Google Sheet (รอ Sheet ID และหัวข้อข้อมูลของแต่ละแผนก)

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ตั้งค่าแผนก (`DEPARTMENTS`: ชื่อ สี Sheet ID อีเมลเจ้าของ เมนู), `doGet`, เข้า/ออกระบบ, ตรวจตั๋ว |
| `Admin.gs` | รหัสผ่าน: แผนกตั้ง/เปลี่ยนรหัสเองในหน้าเว็บ, ผู้ดูแลระบบออกรหัสตั้งค่า/ปลดล็อก, รหัสผู้ดูแลยืนยันทางอีเมล |
| `Setup.gs` | เครื่องมือเสริมใน editor: ตรวจสถานะ (`checkSetup`), ปลดล็อก (ไม่ใช้ตั้งรหัสผ่านแล้ว) |
| `Api.gs` | API (doPost) ให้หน้าเว็บบน GitHub Pages เรียก — เรียกได้เฉพาะฟังก์ชันในรายการ |
| `Index.html` | หน้าแจ้งลิงก์ใหม่ (เมื่อเปิดลิงก์ Apps Script ตรง ๆ) · หน้าเว็บจริงคือ `index.html` ใน repo Department |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (เขตเวลา Asia/Bangkok, Web App รันในนามเจ้าของสคริปต์) |

## ความปลอดภัย / การแยกแผนก

- **กรอกรหัสทุกครั้ง** — ตั๋วเข้าระบบเก็บในหน่วยความจำหน้าเว็บเท่านั้น (ไม่ใช้ cookie / localStorage)
  รีเฟรชหรือปิดหน้า = ต้องกรอกใหม่ ไม่ใช้งาน 30 นาทีหมดอายุ
- **รหัสผ่านไม่อยู่ในโค้ด** — เก็บเป็นค่าแฮช SHA-256 + salt ใน Script Properties
- **รหัสผ่านรู้เฉพาะคนในแผนก** — แผนกตั้ง/เปลี่ยนเองในหน้าเว็บ ผู้ดูแลระบบไม่เห็นและตั้งแทนไม่ได้
  ผู้ดูแลระบบทำได้แค่ออก "รหัสตั้งค่า" (ใช้ครั้งเดียว 3 วัน) ให้แผนกไปตั้งรหัสเอง — ใช้ทั้งครั้งแรกและตอนลืมรหัส
- **เปลี่ยน/รีเซ็ตรหัสแล้ว เครื่องอื่นที่ค้างอยู่ถูกออกจากระบบทันที**
- **ไม่ตรวจรหัสซ้ำข้ามแผนก** — ถ้าตรวจ แผนกหนึ่งจะลองเดารหัสของแผนกอื่นได้ (รหัสแต่ละแผนกใช้ได้กับแผนกของตัวเองเท่านั้นอยู่แล้ว)
- **ผู้ดูแลระบบ** — ตั้งรหัสครั้งแรก/ลืมรหัส ยืนยันด้วยรหัส 6 หลักที่ส่งไปอีเมลเจ้าของระบบ
- **ข้อมูลแยกแผนก** — ตั๋วผูกกับแผนกเดียว ฝั่ง server เปิดได้เฉพาะ Google Sheet ของแผนกในตั๋ว
  (`openDeptSpreadsheet_`) ไม่มีทางขอข้อมูลข้ามแผนกจากหน้าเว็บ
- **กันเดารหัส** — ผิด 5 ครั้งติด ล็อกแผนกนั้น 10 นาที

## ติดตั้ง (ครั้งแรก)

1. สร้างโปรเจกต์ Apps Script ใหม่ในบัญชีเจ้าของระบบ แล้วสร้างไฟล์ `Code.gs`, `Setup.gs`, `Index.html`
   (ชื่อ `Index` ตรงตัว) วางโค้ดจากโฟลเดอร์นี้
2. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone** (หน้าเว็บบน GitHub เรียก API ได้โดยไม่ต้องล็อกอิน Google — เข้าแผนกต้องใช้รหัสผ่านแผนก) → ได้ลิงก์ `/exec`
   (ครั้งแรกเจ้าของสคริปต์ต้องกดอนุญาตสิทธิ์: Run `checkSetup` ใน editor หนึ่งครั้ง)
3. เปิดเว็บแอป → **ผู้ดูแลระบบ** → ส่งรหัสยืนยันไปอีเมลเจ้าของระบบ → ตั้งรหัสผู้ดูแล
4. ในหน้าผู้ดูแล กด **ออกรหัสตั้งค่า** ของแต่ละแผนก → ส่งรหัสให้หัวหน้าแผนกเอง
5. แผนกกดการ์ดแผนก → ใส่รหัสตั้งค่า → ตั้งรหัสผ่านของแผนกเอง (เปลี่ยนได้ตลอดที่เมนู "เปลี่ยนรหัสผ่าน")

## เชื่อม Google Sheet ของแต่ละแผนก (ขั้นถัดไป)

1. ใส่ `sheetId` (และ `ownerEmail`) ของแต่ละแผนกใน `DEPARTMENTS` (Code.gs)
2. เจ้าของชีตแต่ละแผนกแชร์ชีตให้บัญชีเจ้าของสคริปต์เป็น **ผู้แก้ไข** (ผู้ใช้หน้าเว็บไม่ต้องมีสิทธิ์ในชีต)
3. Run `checkSetup` ดูว่าทุกแผนกเปิดชีตได้ แล้ว Deploy → Manage deployments → แก้เวอร์ชันเป็น New version

## เริ่มด้วยระบบกลาง (แบบ 1) แล้วย้ายบางแผนกไปแยกเอง (แบบ 2) ภายหลัง

โค้ดชุดเดียวใช้ได้ทั้งสองแบบ — ย้ายทีละแผนกได้ แผนกอื่นใช้ระบบกลางต่อตามปกติ

**ช่วงแรก (แบบ 1)** — แผนกที่ยังไม่มีอีเมล: สร้างชีตของแผนกไว้ใน Drive ของบัญชีกลาง
(แยกโฟลเดอร์ละแผนก) ใส่ `sheetId` ใน `DEPARTMENTS` ตามปกติ

**ตอนแผนกพร้อมมีอีเมลของตัวเอง (ย้ายไปแบบ 2)** — ตัวอย่างแผนก HR:

1. **โอนความเป็นเจ้าของชีต** HR ให้อีเมลของ HR (Drive → แชร์ → ตั้งเป็น "เจ้าของ" → HR กดยอมรับ)
   ไฟล์เดิม Sheet ID เดิม ข้อมูลอยู่ครบ ไม่ต้องคัดลอก
2. ล็อกอินอีเมล HR → สร้างโปรเจกต์ Apps Script ใหม่ → วางโค้ดชุดเดียวกันทั้งหมด → ตั้ง `ONLY_DEPT = 'HR'`
3. Deploy เป็น Web app → ได้ลิงก์ `/exec` → ตั้งรหัสผู้ดูแลของระบบ HR → ออกรหัสตั้งค่า → HR ตั้งรหัสผ่านเอง (รหัสผ่านไม่ติดมากับโค้ด)
4. กลับมาที่ระบบกลาง: ใส่ลิงก์นั้นใน `appUrl` ของ HR → Deploy เวอร์ชันใหม่
   การ์ด HR ในหน้าแรกจะพาไประบบของ HR และระบบกลางจะไม่ให้เข้า/ไม่แตะชีต HR อีก
5. HR **เอาสิทธิ์ของบัญชีกลางออกจากชีต** — นับจากนี้บัญชีกลางมองไม่เห็นข้อมูล HR

ผู้ใช้ยังเข้าจากลิงก์ระบบกลางลิงก์เดิมได้ (กดการ์ดแล้วไประบบของแผนก) หรือบุ๊กมาร์กลิงก์ของแผนกโดยตรงก็ได้
เวลาแก้โค้ดในอนาคต: แผนกที่แยกไปแล้วต้องวางโค้ดใหม่ในโปรเจกต์ของตัวเองด้วย (คง `ONLY_DEPT` ไว้)
